## Ограничения фактически выполненной проверки

- **Реальная PostgreSQL не проверена:** ни `DATABASE_URL`, ни отдельный `TEST_DATABASE_URL` не предоставлены. Запуски `db:migrate` и `db:seed` завершились контролируемой ошибкой конфигурации; никаких таблиц в облаке не создавалось. Применение SQL, Aiven TLS, реальные каскады и конкурентные транзакции необходимо проверить после заполнения конфигурации. Для этого подготовлен `npm run test:postgres` с временной схемой в отдельной удалённой тестовой БД. Этот набор не запускался; обычные тесты не заменяют его.
- **Docker build / container smoke-test не выполнены:** Docker CLI в среде отсутствует. Multi-stage Dockerfile подготовлен; проверка Linux AMD64 выполняется командами из README на машине с Docker. Проверенный локальный Node-запуск не является проверкой контейнера.
- Ресурсы Aiven, Yandex Cloud и GitHub не создавались и не настраивались.

Для реального запуска заполните `.env`, выполните `npm run db:migrate`, `npm run db:seed`, затем `npm run start:dev`. Подробные инструкции, TLS CA, Docker и deployment prerequisites — в [README](README.md).
